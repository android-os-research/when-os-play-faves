# vuln-040 · `org.ifaa.aidl.manager` · MIUI (Xiaomi · Redmi · Poco)

## Metadata
| Field | Value |
|---|---|
| Vendor | MIUI (Xiaomi · Redmi · Poco) |
| Package | `org.ifaa.aidl.manager` |

| Threat type | permission_grant_bypass |
| Affected firmware | 393 images |

## Privacy Impact
The hardcoded package 'org.ifaa.aidl.manager' is whitelisted in XSpaceConstant.REQUIRED_APPS and added to permission-granting lists without user consent, allowing it to bypass permission checks.

## Attack Surface
A pre-installed or privileged app can leverage the org.ifaa.aidl.manager package to gain automatic permission grants and access to sensitive APIs (biometric, location, contacts, etc.) without user interaction or visibility.

## Call Graph
```
- `XSpaceConstant.<clinit>() [line ~141: const-string 'org.ifaa.aidl.manager']`
- `XSpaceConstant.<clinit>() [line ~141: sget-object REQUIRED_APPS + addAll()]`
- `XSpaceManagerServiceImpl.<clinit>() [line ~141: sget-object REQUIRED_APPS from XSpaceConstant]`
- `XSpaceManagerServiceImpl.onPackageCallback() [PKG_QUERY + SYS_PROP_WRITE gating permission decisions]`
```
